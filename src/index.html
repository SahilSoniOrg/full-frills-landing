For the nerds: how the maths works

Computed, not cached.

Most apps store "Current Balance" as a number. We derive it from your history every time. The math is always right.

Every entry balances: what leaves one account lands in another, so the totals always add up.

// Ledger Entry const entry = {   id: "tx_123",   splits: [     { acct: "Assets:Bank", cr: 150.00 },     { acct: "Exp:Groceries", dr: 150.00 }   ] }; // sum(dr) === sum(cr)
